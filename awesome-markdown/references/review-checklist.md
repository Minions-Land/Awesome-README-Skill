# README Review Checklist

Use this checklist before returning a generated or revised README.

## Structure

- Title, one-sentence purpose, and primary visual appear before long background.
- Badges are accurate and not excessive.
- Quick-start instructions are visible without expanding a collapsed section.
- Headings form a clear hierarchy.

## GitHub Compatibility

- Code fences are balanced and labeled.
- Mermaid, GeoJSON, TopoJSON, STL, and math blocks use GitHub-supported syntax.
- Images use valid relative paths or stable URLs.
- HTML is limited to safe display helpers such as image sizing, centering, and `<kbd>`.
- No JavaScript, iframes, or external CSS are required.

## Readability

- Tables are narrow enough to scan on GitHub.
- Alerts are short and reserved for important information.
- Collapsible sections hide optional details only.
- Diagrams have enough surrounding text to remain understandable if rendering fails.
- Alt text describes what each image or GIF shows.
